# Como Publicar e Atualizar no GitHub Pages

## 1. Preparar o repositório

1. Confirme que todos os arquivos principais existem na raiz do projeto: `index.html`, `style.css`, `app.js`, `data/` e `assets/`.
2. Verifique se as referências de arquivos estão corretas.

## 2. Ativar Pages

1. Acesse o repositório no GitHub.
2. Vá em **Settings** → **Pages**.
3. Selecione a branch principal e a pasta raiz (`/root`).
4. Salve e aguarde a publicação.

## 3. Atualizar após alterações

1. Faça commit e push das mudanças.
2. GitHub Pages publica automaticamente a versão mais recente.

## 4. Dicas

- Use caminhos relativos (`assets/...`, `data/...`).
- Verifique sempre se os arquivos visuais existem antes de publicar.
- Teste a página após cada alteração importante.
